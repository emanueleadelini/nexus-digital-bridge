# **App Name**: Nexus Digital Bridge

## Core Features:

- User Authentication and Roles: Enable user registration with roles: Company, Institute, and Admin. Implement secure password management and confirmation emails.
- Admin Management: Restrict admin creation to the primary admin. Implement functionality for adding, modifying, and deleting sector categories.
- Company Profiles: Create and manage company profiles including 'di visura' data, such as name, VAT number, address, website and multiple industry sectors (taken from Confindustria).
- Institute Profiles: Create and manage institute profiles including name, address, and type (taken from the ministry of education).
- Student CV Upload: Enable institutes to upload student profiles containing CV information and tag them with one or more industry sectors.
- Matching Engine: Implement a matching algorithm that identifies matches between company sectors and student CV sectors.
- Real-Time Chat: Enable real-time chat between Companies and Institutes to foster collaboration, including topic for discussing students that companies show interests

## Style Guidelines:

- Primary color: Deep blue (#1A237E) to convey professionalism and trust.
- Background color: Very light gray (#F5F5F5) for a clean, modern look.
- Accent color: Bright orange (#FF9800) to highlight key actions and elements.
- Headline font: 'Space Grotesk' (sans-serif) for a contemporary, techy feel. Body font: 'Inter' (sans-serif) for readability.
- Use modern, outline-style icons to represent different industries and profile sections.
- Maintain a clean, grid-based layout to ensure information is easily accessible and well-organized.
- Use subtle transitions and animations to enhance user experience without being distracting.
